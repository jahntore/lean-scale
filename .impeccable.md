## Design Context

### Users
Hyprland users with a webcam who want the desktop to remain readable as they lean back in a chair. The core use case comes directly from the creator's request: estimate distance and adapt monitor scaling.

### Brand Personality
Simple, cool, benefit-led. The creator asked for a short, selling README and a distinctive infographic, not an elaborate product website.

### Aesthetic Direction
An illustrated explanation of normal posture versus leaning back. Use a restrained editorial composition, warm paper, dark ink, and a single rust-orange accent. Keep assets self-contained and readable on GitHub.

### Design Principles
- Lead with comfortable reading, then explain the technology.
- Show the posture-to-scale relationship rather than decorating with abstract graphics.
- Keep the main README short; put operational detail in a guide.
- Public documentation and infographic text use Norwegian Bokmål. Keep the lean-scale name, commands, configuration keys, and original license text unchanged.
- Be candid about experimental behavior, window reflow, and local camera processing.
- Supply meaningful alternative text; do not rely on color alone.
